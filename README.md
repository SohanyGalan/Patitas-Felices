# 🐾 Clínica Veterinaria Patitas Felices

Página web completa y responsive para una clínica veterinaria en Santo Domingo, República Dominicana.

## 🚀 Tecnologías
- HTML5 semántico
- CSS3 personalizado (variables, degradados, animaciones, media queries, modo oscuro)
- Bootstrap 5.3.0 (CDN)
- Font Awesome 6.0 (CDN)
- JavaScript (validaciones, carrusel, modal, persistencia con localStorage, analítica ligera)

## 📂 Estructura
```
clinica-veterinaria-patitas-felices/
├── index.html   → estructura y contenido
├── style.css    → estilos personalizados
└── script.js    → interactividad
```

## ✨ Funcionalidades
- Menú fijo responsivo con enlace activo según la sección visible
- Banner al 100 % del ancho con CTA
- 3 servicios, 3 veterinarios y 10 testimonios en carrusel (4 por vista)
- Bordes arcoíris animados y fotos con efecto de latido
- Formulario validado que abre la app de correo y muestra un modal de confirmación
- Botón de WhatsApp y enlaces de teléfono funcionales
- Modo claro/oscuro recordado por el navegador
- SEO (meta etiquetas, Open Graph, datos estructurados Schema.org) y accesibilidad (A11y)

## ▶️ Cómo verlo
Abre `index.html` en el navegador o usa la extensión **Live Server** de Visual Studio Code.
